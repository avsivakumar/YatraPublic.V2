# Yatra V2 overview

Yatra is an open-source architectural sample created by Sivakumar Angarai for asynchronous agent-to-human interaction. V2 combines conversation text, original dynamic forms and compiled trusted React component experiences. It demonstrates boundaries and recovery, not a production agent platform.

The adapter chooses an approved exact contract and data. The engine transports, correlates and persists it without depending on React or concrete components. The generic browser host validates, renders and owns response identity, HTTP, retry and lifecycle. Private return paths never enter the browser.

Try `compare customers` for a selectable comparison or `show status summary` for acknowledgement. Existing form commands and ordinary Fake LLM chat remain. Browser capabilities describe only registered ID/version/action pairs; missing explicit support falls back safely. Executable agent-generated UI and remote modules are excluded.
